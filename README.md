**I measure what actually happens, not what the label says.** The first number people see is usually the
flattering one. The number that decides is a different one, so I go and measure it:

- [Porchlamp](https://porchlamp.org/): what happens to a stranger's pull request, not how many stars a project has.
- [RL Alpha Labs](https://rlalphalabs.com/): what a trading idea keeps after real costs and tax, not its best backtest.
- [GLM-5.3 on one GPU](https://github.com/pctablet505/glm53-flash-single-gpu): what one 96 GiB card really serves,
  not what it is rated for.

In open source: [100 merged pull requests in 38 projects](https://github.com/search?q=is%3Apr+author%3Apctablet505+is%3Amerged+-user%3Apctablet505&type=pullrequests),
64 of them in Keras and KerasHub (counted 21 October 2026).

One result I did not expect: the more stars a project has, the more often a stranger's pull request goes
unanswered. [The numbers are here.](https://porchlamp.org/black-holes/)
